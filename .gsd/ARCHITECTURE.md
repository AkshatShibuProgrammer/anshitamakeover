## Data Flow

1. **User Request / Browsing:** Client initiates request → `django/core/urls.py` routes to view → view queries models (`SiteSettings`, `LookGroup`, `MakeupPackage`) → renders cached/context-enhanced template with localized i18n strings.
2. **AI Consultation:** User chats with Concierge → Three.js avatar reacts to cursor coordinates → AJAX POST to `/api/chatbot/` → backend checks negotiation floor rules in `SiteSettings` → delegates prompt to Google Gemini API → logs chat to `ChatMessage` → streams structured response to UI.
3. **Admin Real-time Edits:** Admin edits album name or pricing on UI → JS invokes `/api/admin/lookgroup/` or `/api/admin/price/` → backend validates permissions and updates Django ORM → returns JSON status → DOM updates instantaneously.
