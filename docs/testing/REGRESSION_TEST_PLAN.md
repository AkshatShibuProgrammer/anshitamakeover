## 2. How to run

```bash
# one-time setup
make venv && testenv/bin/python -m playwright install --with-deps chromium

python testing/run_all.py            # ⭐ MASTER: every kind of testing
python testing/run_all.py --list     # suites + runtime availability
python testing/run_all.py --suite unit api   # selected suites
make unit                   # Django suite only
make api                    # API contract (boots own server on :8121)
make e2e                    # Playwright E2E (boots own server on :8122)
make bdd                    # Karate (needs Java 11+ & Maven + running server)
make smoke                  # HTTP smoke check against a running server
make perf                   # performance budget check
```

CI (`.github/workflows/regression.yml`) runs all five jobs on **every push and PR**.

## 9. Maintenance guide

* **Add a feature** → add factories to `testing/testdata/factories.py`, unit tests with the
  next TC id, mirror an API scenario in `testing/api` **and** `testing/bdd/`.
* **Regenerate fixture** after factory changes:
  `python testing/testdata/generate_fixture.py`
* **Re-seed dev DB**: `python manage.py seed_test_data --wipe`
* **New known defect** → lock it with a test referencing KD-xxx and add a row
  to §7.
